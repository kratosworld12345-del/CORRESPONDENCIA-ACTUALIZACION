# CORRESPONDENCIA-ACTUALIZACION

Repositorio público de actualizaciones del **Generador de Documentos por Correspondencia**.

- `version.json`: versión vigente del programa y enlace a su instalador.
- **Releases**: instaladores publicados (`ExportadorIFI_Setup.exe`).

Este repositorio no contiene código fuente ni configuración. El programa necesita una licencia autorizada para
funcionar.
